### Краткое описание 
Системы очередей (Kafka)

- Принимает события создания и обновления пользователей в формате JSON
- Отправляет эти события в Kafka (продюсер - UserEventProducer)
- Обрабатывает события через два отдельных консьюмера:
  1. UserEventConsumer - логирует короткое сообщение
  2. UserEventLogger - выводит подробную информацию об изменении
